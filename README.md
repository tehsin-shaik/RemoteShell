# RemoteShell
A remote command-line shell implemented in C using Linux processes, inter-process communication, pipes, and TCP sockets.

# Overview
RemoteShell is a network-enabled command-line shell built in C for Linux. It brings together process management, command pipelines, and TCP socket communication to enable remote command execution through a client-server architecture.

Designed around core operating system concepts, RemoteShell aims to provide a lightweight, terminal-based interface for executing commands locally and remotely.

# Project Phases
Phase 1: Local CLI Shell
Phase 2: Remote CLI Shell
Phase 3: Remote Multitasking CLI Shell
